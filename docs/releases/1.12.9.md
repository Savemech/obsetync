# ObsetyNC 1.12.9

## Changes

- Fresh downloads report completed files and transferred bytes while they run,
  including checkpointed chunks of large files. The status bar and resource
  governor no longer wait for the entire diff or page to finish.
- Small-file writes can recover from conservative concurrency limits when
  foreground performance is healthy. Each apply window reads the current
  limit, and every write remains inside its admitted download batch. Existing
  transfer memory budgets and staged large-file downloads are preserved.
- Download echo tracking starts immediately before each disk mutation. Long
  downloads no longer expire expectations for files that have not been written,
  which previously queued downloaded files as local changes after 60 seconds.
- Automatic startup sync waits 30 seconds by default. Configure **Startup
  delay** from 0 to 300 seconds, use **Sync now** to start immediately, or run
  **Pause startup sync** to remain paused until a manual sync. Unloading the
  plugin cancels its pending startup.

## Verification

Regression checks cover long fresh downloads through legacy and paged diffs,
live progress without duplicate totals, bounded apply concurrency changes,
resumed large-file progress, governor recovery and UI-lag backoff, and startup
cancellation. Plugin tests, TypeScript checking, and the local production build
pass. Real iPad throughput and peak process memory remain to be measured; these
changes do not establish a device-wide memory or crash-free guarantee.

## Upgrade

Update ObsetyNC through BRAT, or install the release ZIP. This patch introduces
no sync protocol or local-store migration. The **Sync Priority** setting still
controls upload order; download ordering is unchanged.
