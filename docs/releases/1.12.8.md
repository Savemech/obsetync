# ObsetyNC 1.12.8

## Changes

- Added an opt-in editor typing latency probe. It measures trusted CodeMirror
  input through the second animation frame, keeps only bounded timing samples,
  and stops at visibility or lifecycle boundaries.
- Added regression coverage for a file changing into a directory between stat
  and read. The failed attempt must retain its journal generation and retry
  safely without publishing a root or base.

The file-sync wire protocol, persisted formats, and minimum Obsidian version
remain unchanged from 1.12.7. Character-level collaborative editing remains
disabled; concurrent edits continue to use the existing conflict-copy and
history protections.

## Platforms and verification

The plugin targets Windows, macOS, Linux, iOS/iPadOS, and Android. Automated
plugin, Rust, WASM parity/memory, native integration, Docker E2E, Nix, and
release-provenance gates cover this release candidate. Numerical real-device
typing, RSS, suspend/resume, reload, and prolonged soak qualification remains
open and is not claimed by these automated checks.

## Upgrade and recovery

The release contains the flat Obsidian/BRAT assets and a complete zip. No local
store migration is introduced. If the new diagnostic build causes a problem,
disable ObsetyNC or reinstall the 1.12.7 plugin assets while preserving the
vault and ObsetyNC journal/state. Export debug information before recovery when
possible. Do not delete the only local copy, clear server data, or use Full
Rescan as a generic recovery step.
